# DC Animated Graph

An interactive map of DC animated movies and TV shows (no live action), from 1966 to today.

**Live:** https://veltrynox.github.io/dc-animated-graph/

- Each poster is a node, and arrows show story order
- Layouts: release date, collection, or story chain
- Pick a character to highlight every title they appear in
- Click a poster for details and what comes next in the chain

Plain HTML/JS with [Cytoscape.js](https://js.cytoscape.org/). No build step.

Posters © DC / Warner Bros., loaded from dc.com. This is an unofficial fan project.
